# Put your own copy online with Cloudflare

Your own Cloudflare account hosts both the app and D1 database. Firebase and Supabase are not required. No seller account, links, credentials or database IDs are included.

1. Install supported [Node.js 22 or newer](https://nodejs.org/en/download), extract this ZIP and open a terminal in its folder. Run `npm install`. Node and Wrangler are development tools; there is no Link Launcher EXE.
2. Sign in to [Cloudflare](https://dash.cloudflare.com/). Check **Compute → Workers plans → Free**. Do not choose a paid plan or purchase a domain.
3. Run `npm run cloudflare -- login`, authorize Cloudflare's Wrangler app, then run `npm run cloudflare -- whoami`. Confirm the account is yours. If you have several accounts, add the intended `account_id` to `wrangler.jsonc`.
4. Run `npm run cloudflare -- d1 create link-launcher-vault`. Replace the all-zero **database_id** in `wrangler.jsonc` with the returned ID. Keep the binding **DB**. If a Worker named link-launcher already exists, change the Worker `name` to a unique name first.
5. Run `npm run cloudflare -- d1 migrations apply link-launcher-vault --remote`. This creates an empty database; it does not transfer the seller's data.
6. Set `web/cloud-config.js` to `window.LINK_LAUNCHER_CLOUD = { apiUrl: '', localOnly: false };`. The app and API share the same origin.
7. Run `npm run cloudflare -- secret put JWT_SECRET`. Enter a fresh random secret of at least 32 characters, generated by your password manager. Accept if Wrangler offers to create the new Worker. Keep the secret stable and private; never put it in `web/`, a public repository or chat.
8. Run `npm run deploy`. Open the printed HTTPS `workers.dev` address. `/api/health` should report D1 connected and `migrationPending: false`.
9. The new address has its own installation code. Send it to the seller through your paid order and import the signed `.lllicense` for this browser. One person can have up to three installations. A localhost licence does not activate a different address.
10. Select **Create Account**, use your purchase email and choose/confirm a master password of at least 12 characters. On another licensed browser, sign in with the same email/master password. Use **Choose profiles for this device**, name the browser installation (for example Home PC or My phone), select the profiles you use there and save. Existing and future links in those profiles appear in **This device**, alongside individually saved/assigned links. **All devices** keeps the complete account library. New browsers start with their own selection; clearing browser data requires choosing again. Profiles are shared labels, not automatic detection of Chrome profiles or separate access permissions.

To move local links: export an encrypted `.dlvault` first. Create the fresh cloud account with the same email/master password and import the backup. Import replaces the selected destination vault and syncs that replacement; check the destination first. Browser caches do not move between addresses automatically.

Install on PC using Chrome/Edge's **Install app** action. On a phone use **Add to Home Screen / Install app**. First loading and account creation need internet. Cached links reopen offline with the master password. Reopening offline requires signing in online before cloud sync reconnects. Linked websites may still require internet.

Current free allowances include **100,000 Worker requests/day**, **5 million D1 rows read/day**, **100,000 rows written/day**, **5 GB total account storage**, and **500 MB per D1 database**. CPU and other platform limits apply. Quotas can pause cloud operations. Check current [Workers limits](https://developers.cloudflare.com/workers/platform/limits/), [D1 limits](https://developers.cloudflare.com/d1/platform/limits/) and [D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/). Hosting is not unlimited.

The API receives the account email, a derived authentication verifier, encrypted vault and sync metadata. The master password stays in browser memory while unlocked; optional trusted-browser unlock keeps an encrypted local copy with a browser-held key. There is no password recovery or verified-email identity flow. Keep private deployments for your own licensed use.

Keep encrypted backups outside the browser. Clearing browser data removes local copies and activation; request replacement installation approval through your order when needed. Your cloud administration and billing decisions remain your responsibility.

## Saved workspaces, automatic unlock and browser links

Name each workspace, such as Home PC or Work laptop, and save its profiles. In a new browser, open Choose profiles for this device and select Home PC from Saved workspace to reuse its selection. Names and selections sync in your encrypted vault; the browser remembers your chosen workspace locally. Incognito cannot identify the physical PC and forgets that local choice when closed.

Select Keep this browser unlocked only on your own trusted browser. It remembers the password locally using a browser encryption key, for up to 90 days. Anyone who can open that browser can access the vault. Lock or Log Out removes remembered access. Incognito forgets it when closed.

To open each account in its assigned Chrome or Edge profile, open Browser profiles and download the extension and Windows helper. Extract browser-bridge.zip into a permanent folder; load the extension through chrome://extensions or edge://extensions. Double-click Setup.cmd from the extracted browser setup folder. A private official runtime is downloaded and checksum-verified if needed. Load/reload the extension and refresh the app.

For your own HTTPS deployment, edit the first matches entry in the extracted extension manifest.json to your actual app origin plus /*, then reload the extension. The buyer ZIP includes a placeholder origin and localhost support only.


Colours: click the small coloured dot beside an account to change its colour; click the palette button above the links to change a category tab. Colour choices sync in the encrypted vault. All devices resets the Starred/Pinned account filter and shows every saved account, including accounts with no links. If a Chrome/Edge profile is missing, use Find browser profiles on this PC and select the accounts to add. Names/emails are saved in the encrypted vault only after you choose Add selected accounts; browser locations and routing stay local. Add Link accepts a pasted website address and displays both name and email to distinguish accounts. The interface uses restrained colour accents, rounded controls and a subtle frosted-glass header/dialog finish.
