DREAMSLAB / LINK LAUNCHER

A calmer home for your links.

Save and organise links, switch workspaces and keep an encrypted backup. Explore each tab to get started.

Start with a local-only vault

Choose Open / create local-only vault, enter and confirm a master password. Add links with Add Link. This browser keeps encrypted records; download backups before clearing site storage.

Your library on PC and phone

Create an account with an email identifier and a master password of at least 12 characters. Sign in at the same URL on another device. New accounts start empty. Choose profiles for this device to save a workspace; All devices shows the complete library.

Open links in the right browser

Windows Chrome/Edge: download Browser profiles → Setup, extract permanently, read READ-FIRST.html, load the unpacked extension and run Setup.cmd. Reload and assign browser profiles. Phones open links normally. The add-on is not on the Chrome Web Store.

Make accounts easy to recognise

Use the coloured dot to change account colour and the palette to change category colour. All accounts clears the account filter. Click an account to filter links; use its three-dot button for options.

Keep a copy you control

Export encrypted .dlvault files before changing URL or clearing browser data. Import replaces the selected vault after confirmation. Readable JSON contains private information. There is no lost-password recovery; sync is not independent backup.

Host on your own account

Fork or download the source. Follow docs/SETUP.md for your own Cloudflare Worker and D1, GitHub transfer, branding and extension URL. No Supabase is required. Keep JWT_SECRET and account files out of GitHub.
