Link Launcher
Browser profile extension

Opens a saved link in its assigned Chrome or Edge profile, instead of the default profile.

Why this extension is needed

A website cannot switch browser profiles by itself. This extension connects the Link Launcher page to an optional helper on your Windows PC.

Permissions

App page access: exchanges launch requests only with the app addresses in its manifest.

Native messaging: talks to the installed Link Launcher helper. The helper reads local profile names, emails, theme colours and raster photos, then launches the selected profile.

Data used

The helper receives the vault account email, selected account label and clicked website address. It does not read passwords, cookies, history or your vault collection. Profile menu actions open the browser’s own settings or password manager. Photos and colours are used locally.
